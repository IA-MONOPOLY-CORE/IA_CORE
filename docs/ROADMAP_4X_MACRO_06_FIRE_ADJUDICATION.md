# Roadmap 4.x Macro-Mission 06 - FIRE Adjudication

## Decision

```text
CANDIDATE: FIRE
DECISION: MERGE
TYPE: DERIVED_INTELLIGENCE_CAPABILITY
LOCATION: METHOD_SANTI_AND_GOKV_EVIDENCE_DERIVATION
IMPLEMENTATION: NOT_STARTED
FIRE_G0: DEFERRED_AS_A_READ_ONLY_DEVELOPMENT_PROFILE
CONFIDENCE: HIGH
```

The repository contains the raw ingredients for failure and resilience
intelligence: invalidated validation attempts, explicit repair commits,
historical guards, rollback contracts, bounded failure states and adversarial
assurance. It does not contain a FIRE component, nor does it need one for this
mission.

## Current equivalents

| FIRE concept | Current source | Boundary |
| --- | --- | --- |
| Failure case and pattern | test failures, `failures` ledgers, historical impact tests | Derived only; source bytes remain unchanged |
| Failure fingerprint/locality | commit/file manifests and validation cohorts | Report metadata, not runtime detection |
| Propagation/common mode | cross-boundary P1 tests and invalidation records | Evidence-based hypothesis only |
| Resilience evaluation | retry/repair/rollback fields, bounded route contracts | Method owns remediation design |
| Coverage map and resilience debt | route matrices, test cohorts and deferred frontiers | Documentary planning only |
| Aging defense | historical guard compatibility and V2 anti-weakening tests | Method/test infrastructure owner |

## Ownership

```text
SOURCE REALITY: repository tests, Git and canonical evidence
CANONICAL PROVENANCE: DOOL/GOKV contracts
DERIVATION: future FIRE evidence profile under Method Santi
REMEDIATION DESIGN: Method Santi
AUTHORIZATION: Security boundary
EXECUTION: existing Foundry/runtime only under separate authorization
INHERITANCE: OCI
GLOBAL LEARNING: GOKV promotion rules, never FIRE auto-promotion
```

FIRE may classify and compare evidence. It may not rewrite source evidence,
fabricate incidents, run destructive chaos experiments, authorize or execute
remediation, expose raw logs, activate runtime, promote learning, or claim
causality from correlation.

## Minimum future G0

A future FIRE.G0 could consume only canonical, development-origin evidence and
emit a bounded report of invalidated Level B runs, stale fixtures, repair paths,
rollback/retry patterns, isolation outcomes and uncovered controls. It would be
read-only, deterministic, reversible, privacy-bounded and explicitly
non-productive. This mission does not implement it.

## Name compatibility

`FIRE` is descriptive enough for a candidate derived-intelligence profile, but
it is not a Cognitive Kernel family, fifth pillar, permission, endpoint or
runtime component. The name remains provisional until a future contract proves
its vocabulary does not collide with security incident terminology.
