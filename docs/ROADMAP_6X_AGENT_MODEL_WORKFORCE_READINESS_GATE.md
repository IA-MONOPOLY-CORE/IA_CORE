# Roadmap 6.x - Agent and Model Workforce Readiness Gate

## Gate

`ROADMAP_3_0_A_N5_WORKFORCE_READINESS_GATE_DEFINED`

## Purpose

`ROADMAP_6X_ENTRY_AGENT_MODEL_WORKFORCE_READINESS_GATE` is a future mandatory
entry gate before controlled business operation of agents and teams. The name
marks the intended roadmap family, not a decision that it must execute exactly
as version 6.0. It must be placed at the correct point after its dependencies
are actually closed.

IA_CORE must not claim `READY_TO_CONSTITUTE_BUSINESS` while critical workforce,
model, memory, permission, team or capacity evidence is missing.

## Required gate dimensions

### A. Agent workforce coverage

For every relevant profile, role and specialization: total, `READY`, `PARTIAL`
and `NOT_READY`, with provenance and current contract references.

### B. Workforce gaps

Missing preset, paper seed, model policy, memory policy, capability contract,
permission contract, team compatibility, hierarchy compatibility and business
coverage must be explicit rather than inferred.

### C. Business coverage

For each business class/type: required capabilities, roles, blueprints, ready
agents, missing agents, team template, model requirements, memory requirements,
ideal hierarchy, minimum hierarchy, hardware-fitted hierarchy and readiness.

### D. Organizational capacity

Ideal agent count, minimum functional count, maximum recommended concurrency,
serialized roles, cloud/hybrid alternatives and local-only constraints.

### E. Model capacity

Compatible and recommended local models, cloud fallback, model tier by
hierarchy, availability and installed state as separate facts.

### F. Memory and privacy

Agent logical memory, team memory, business memory, sharing contracts and
privacy/isolation evidence.

## Dependencies

- **Roadmap 3.x:** backend truth, security, API activation boundaries, agent,
  provider, memory and sandbox contracts.
- **Roadmap 4.x:** professional/business coverage evidence, capability
  composition, team/hierarchy compatibility and gap classification.
- **Roadmap 5.x:** model/provider catalog maturity, hardware-aware capacity,
  memory namespace policy, organizational recommendation and controlled
  readiness evidence.
- **6.x entry:** only after the above evidence is independently validated and
  the human/operator decision boundary is explicit.

Roadmap 3.0.A defines this gate only. It does not execute the gate, activate
agents, install models, enable runtime, create memory or approve business
operation.
