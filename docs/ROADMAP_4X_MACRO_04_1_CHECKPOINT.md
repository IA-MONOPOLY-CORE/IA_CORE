compatibility, lifecycle and inheritance limits. The cognitive kernel is a
governed composition and not a fourth family.

## Reconciled contracts

DOOL is permanent and G0 is origin rather than sunset. OCI's active future
literal is `NECESSARY_AND_SUFFICIENT_INHERITANCE`; closed historical uses of
the older wording remain unchanged. Agent model fit, fallback, success/failure
inheritance, global capability versus enterprise confidentiality, Owner-native
identity, authority without universal content visibility, future recovery and
domain module parity are documented as bounded contracts.

## Boundaries preserved

P1-A remains `P1-A_PLATFORM_STATUS_HEALTH_SELECTED_NOT_STARTED` and
`TEMPORARILY_PAUSED_BEHIND_COGNITIVE_KERNEL_RECONCILIATION`. P1-B, P1-C and
P1-D remain deferred and not started. None of the four P1 routes is modified or
invoked. Enterprise Foundry remains
`FUTURE_CONCEPT_PRESERVED_NOT_SCHEDULED_NOT_IMPLEMENTED`.

No runtime OCI, cross-tenant learning, provider call, external application
call, permission grant, automatic promotion, secret read, tenant read, model
training, payload activation, product endpoint, UI change, backend change or
Macro-Mission 05 is included.
