## Adversarial boundary

The canonical validator and tests reject malformed JSON, schema drift, unknown
families, duplicate nodes, orphan edges, unknown relation types, invalid
generations, missing G0 evidence, materialized future placeholders, runtime or
provider activation, tenant reads, payload activation, automatic promotion,
obsolete OCI inheritance, Owner isolation bypass, domain privilege and
untrusted/offensive material treated as executable or promoted authority.

Security is a native operating plane, measured rather than marketed, with
defense in depth and deterministic enforcement. Offensive repositories and
malware remain future untrusted evidence only; no exploit, target, clone,
offensive tool or dynamic malware analysis was used.

`SECURITY_IS_A_NATIVE_OPERATING_PLANE`,
`SECURITY_BY_DESIGN_NOT_SECURITY_AS_AN_ADD_ON`,
`DEFENSE_IN_DEPTH_OVER_SINGLE_PRODUCT_DEPENDENCE`,

`SECURITY_STRENGTH_MUST_BE_MEASURED_NOT_MARKETED`,
